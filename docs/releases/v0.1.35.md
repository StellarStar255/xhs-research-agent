## v0.1.35 更新内容

- 修复回答、草稿和导出网页中的危险 HTML，保留表格、列表、代码和正常来源链接。
- 改用跨进程浏览器锁，等待结束后重新检查阅读额度和冷却状态，避免并发任务使用过期额度。
- 改善停止任务、删除对话、启动失败及排队消息自动发送的收尾；API 网络等待期间也能及时停止。
- 减少流式输出的磁盘写入；聊天页面只拉取变化的消息，并保留未变化的历史节点。
- 笔记缓存改为按 ID 索引，每篇笔记独立记录抓取时间；旧缓存首次使用时自动导入。
- API 服务地址和模型、Claude 模型随对话保存；API 密钥按服务地址管理，切换服务商后旧对话继续使用原配置。
- 设置、对话和抓取记录采用原子写入；损坏记录保留为 `.corrupt-*` 文件，调研 ID 增加随机后缀。
- API 长对话保留近期内容，将早期内容整理为答案摘录和笔记索引，减少重复发送历史图片；原始消息和图片仍保存在本地。
- 增加离线回归测试、可选 Chrome 集成验证，以及 macOS、Windows、Linux 自动测试。

升级前的旧对话会在第一次追问时保存当时的模型配置。阅读额度、抓取节奏和冷却时长保持原有设置。
