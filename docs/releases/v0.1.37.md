## v0.1.37 更新内容

- Codex 支持选择具体模型：读取本机 Codex 模型列表，也可手动填写模型 ID。
- Claude Code 支持默认模型、Sonnet、Opus、Haiku，以及手动填写具体模型 ID。
- 增加可选的思考强度。保留“默认”即可使用模型默认强度；Codex 已知模型只显示其支持的档位，Claude 根据本机 CLI 支持的档位显示。
- 模型和思考强度随新对话保存。修改全局设置只影响新建对话，已有对话继续使用原配置。
- 增加模型配置、参数传递和设置页面的回归测试。

升级后在“设置 → 回答问题用的大模型”中选择模型和思考强度。模型能否使用仍取决于本机 CLI 版本和账号权限；手动填写模型 ID 时请确认模型及档位受到支持。
