## 历史搜索和对话整理

- 搜索结果展示命中片段并高亮关键词，点击可定位到匹配消息，支持上一个、下一个。
- 支持仅搜索提问或回答，并按最后更新时间筛选；对话可置顶和归档。
- 完整标题悬停可见，侧栏支持拖动调宽并记忆；⌘K / Ctrl+K 聚焦搜索，方向键选择，Enter 打开。
- 搜索加载失败时保留已有列表并提供重试；多个窗口同步修改，长对话只更新变化的消息。

## 草稿、恢复和备份

- 自动保存每段对话的文字和图片草稿，切换或刷新后恢复；发送失败保留新输入，发送中切换对话不会被拉回。
- 「管理 → 输入草稿」支持查看、恢复、导出和删除。草稿保存在当前浏览器，导出文件包含文字和图片；原生窗口会保存到「下载」。
- 异常退出后保留部分回答、完整排队消息及图片，提供继续回答和恢复到输入框的入口，确认后手动发送。
- 删除先进入回收站，可撤销或恢复；支持包含聊天、图片和笔记的 ZIP 备份，导入前预览并跳过已有记录。
- 「管理 → 磁盘占用」展示各类数据大小，可选择清理回收站或检索缓存。

## 错误诊断与验证

- 回答失败时可查看、复制错误详情；自动隐藏已配置密钥、常见认证字段、Cookie 和网址参数。诊断不会读取聊天正文和应用日志。
- 本机浏览器和原生 WebView 验证草稿持久化、文件导出、ZIP 导入及旧记录恢复；发布流水线在 macOS、Windows 上检查冻结服务和原生 WebView 流程。
- Windows 发布流程实际安装生成的安装包，校验安装文件，并针对安装后的应用运行原生流程检查。

升级会保留现有数据。输入草稿属于本浏览器，不包含在历史 ZIP 中，可在草稿管理中单独导出。
